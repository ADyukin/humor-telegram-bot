# Telegram-тренажёр юмора

Отдельный MVP Telegram-бота для локального запуска.

## Что умеет

- создаёт новую бытовую ситуацию;
- принимает текстовый и голосовой ответ;
- распознаёт голос локальной бесплатной моделью Whisper;
- разбирает шутку и даёт короткое правило с примером;
- сохраняет уровень, попытки, слабые места и освоенные приёмы в SQLite.

## Локальный запуск

```bash
cd telegram-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Заполни `.env` токеном Telegram-бота и ключом OpenRouter, затем:

```bash
python -m humor_bot.main
```

Бот использует long polling, поэтому для локального теста не нужен публичный URL. Ключи не добавляются в репозиторий.

## Бесплатный Render

В `render.yaml` есть конфигурация бесплатного Web Service. Подключи репозиторий к Render и задай `TELEGRAM_BOT_TOKEN` и `OPENROUTER_API_KEY` как секреты.

Ограничения бесплатного тарифа:

- сервис может уснуть после простоя;
- локальная SQLite-база может потеряться после перезапуска;
- первое голосовое сообщение после запуска будет дольше, потому что загружается Whisper.

Для постоянного сохранения прогресса позже нужно подключить внешнюю бесплатную базу.
